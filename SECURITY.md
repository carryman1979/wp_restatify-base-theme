# Security Policy

## Supported Versions

Security fixes are provided for the latest published release of Restatify Base
Theme. Older releases do not receive separate security backports. Please update
to the latest release before checking whether a suspected vulnerability persists.

Download installable theme packages from
[GitHub Releases](https://github.com/carryman1979/wp_restatify-base-theme/releases).
Keep WordPress, PHP, and installed plugins on supported, updated versions as well.

## Reporting a Vulnerability

Please report suspected security vulnerabilities confidentially through
[GitHub Private Vulnerability Reporting](https://github.com/carryman1979/wp_restatify-base-theme/security/advisories/new).
Sign in to GitHub to submit a report.

Do not open a public issue or pull request containing exploit details for an
unfixed vulnerability.

Include the following where possible:

- The affected theme version and relevant WordPress and PHP versions.
- A description of the vulnerability and its potential impact.
- Required access, configuration, and other prerequisites.
- Minimal reproduction steps or a proof of concept using test data.
- Any suggested mitigation or fix.

Do not include real credentials, API keys, personal data, or information belonging
to other users. Test only systems you own or have explicit permission to test.

## Handling and Disclosure

Maintainers will assess the report, may request additional information, and will
communicate through the private GitHub advisory. There is no guaranteed response
or resolution time.

If confirmed, maintainers will coordinate a fix and disclosure, and provide
available update or mitigation guidance. Reporter credit can be discussed before
publication. If the report cannot be confirmed or is outside this project's scope,
maintainers will explain the assessment when possible.

Please coordinate public disclosure with the maintainers so users have an
opportunity to install a fix before exploit details are published.

For ordinary bugs and feature requests that do not expose a security issue, use
[GitHub Issues](https://github.com/carryman1979/wp_restatify-base-theme/issues).
