# Restatify Base Theme 1.2.1

- Image or YouTube background for all 14 custom section blocks.
- Existing overlays, opacity and fullscreen remain available; video supports
  bounded parallax movement.
- Muted looping playback after cookie consent only, offscreen pause and
  keyboard-accessible pause/play controls.
- Consent withdrawal removes players; reduced motion disables video/parallax.
- Local fallback and visible errors for player/autoplay failures.
- Existing image blocks retain their saved output.

PHP 8.0+, WordPress 6.9+. Exact shared dependency remains 1.1.0.
Videos must allow embedding. Update privacy/cookie disclosures for YouTube.
The editor does not connect to YouTube.
