# Restatify Base 1.2.0

- Single-post template with article overview, adjacent articles and comments.
- Blog-grid infinite scroll, retry controls and short-lived session cache.
- Configurable honeypot, reCAPTCHA v3 and Turnstile comment protection.
- Exact Shared 1.1.0 PHP payload is bundled and installed without active plugins.
- PHP 8.0+ and WordPress 6.9+; no automatic changes to Discussion settings.

Update ZIP: `wp_restatify-base-theme-1.2.0.zip`.
Upload through WordPress Appearance → Themes. No external runtime downloads are needed.
Configure comment protection under Settings; disclose the selected CAPTCHA provider in the site's privacy policy.
Local-root Shared remains preferred; other installed shared versions are preserved.
