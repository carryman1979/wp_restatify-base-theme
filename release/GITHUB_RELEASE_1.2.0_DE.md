# Restatify Base 1.2.0

- Single-Post-Template mit Artikeluebersicht, Nachbarartikeln und Kommentaren.
- Infinite Scroll im Blog-Raster mit Retry und kurzlebigem Session-Cache.
- Kommentarschutz mit Honeypot, reCAPTCHA v3 und Cloudflare Turnstile.
- Exakter Shared-1.1.0-Payload enthalten; Installation auch ohne aktive Plugins.
- PHP 8.0+ und WordPress 6.9+; Diskussionseinstellungen bleiben unveraendert.

Update-ZIP: `wp_restatify-base-theme-1.2.0.zip`.
Upload unter Design → Themes. Keine externen Runtime-Downloads erforderlich.
Kommentarschutz unter Einstellungen konfigurieren und den CAPTCHA-Anbieter in der Datenschutzerklaerung beruecksichtigen.
Lokales Root-Shared bleibt vorrangig; andere Shared-Versionen bleiben erhalten.
