# Restatify Base Theme 1.2.2

## Video-Ladebild für YouTube-Hintergründe

- Für Video-Hintergründe kann im Editor ein Bild aus der Mediathek als Ladebild ausgewählt, ersetzt oder entfernt werden.
- Das Bild erscheint bereits vor Cookie-Zustimmung und bleibt sichtbar, bis die Wiedergabe tatsächlich startet.
- Es dient auch bei Playerfehlern und für Besucher mit reduzierter Bewegung als lokaler Fallback; das vorhandene Farboverlay bleibt erhalten.
- Die Editor-Vorschau zeigt dasselbe Bild ohne Verbindung zu YouTube.
- Ohne eigenes Ladebild sowie für bestehende Bildhintergründe bleibt die bisherige Ausgabe unverändert.

## Kompatibilität und Hinweise

- Theme: `1.2.2`; WordPress 6.9+; PHP 8.0+.
- Exakte Shared-Abhängigkeit: `1.1.0`.
- Die YouTube-Wiedergabe startet weiterhin erst nach Cookie-Zustimmung. Cookie-Banner und Datenschutzhinweise müssen YouTube abdecken.
- Dieses Patch-Release enthält keine beabsichtigten Breaking Changes.
