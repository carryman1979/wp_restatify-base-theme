# Restatify Base Theme 1.2.2

## Loading image for YouTube backgrounds

- Choose, replace, or remove a media-library image for video backgrounds in the editor.
- The image is visible before cookie consent and remains until playback actually starts.
- It is also the local fallback for player failures and reduced-motion visitors; the existing color overlay still applies.
- The editor displays the same image without connecting to YouTube.
- Existing image backgrounds and video backgrounds without a custom loading image keep their previous output.

## Compatibility and notes

- Theme: `1.2.2`; WordPress 6.9+; PHP 8.0+.
- Exact shared dependency: `1.1.0`.
- YouTube playback still starts only after cookie consent. Cookie-banner and privacy disclosures must cover YouTube.
- This patch release contains no intended breaking changes.
